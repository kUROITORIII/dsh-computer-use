## 版本号与证据

- 版本号唯一来源：`package.json` 的 `version`。`index.js` 里的 `PLUGIN_VERSION` 只是兜底常量，运行时重新读 `package.json` 写进启动戳。
- 每次启用会覆盖 `%DSH_HOME%/computer-use-start.json`：`{version, tool, at, pid, unknownKeys, schemaProbe}`。**判断"现在跑的是哪一版"看这个文件，不要看代码行数。**
- 改完代码只 `disable → enable` 不一定真重载（ESM 按路径缓存），要么确认启动戳的 `at` 变了，要么把 `version` 也改一下再启用。
